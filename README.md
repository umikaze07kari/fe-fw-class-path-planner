# 万缕千丝 · 职业路线升级助手
# 万紫千紅・兵種ルート育成アシスタント

[简体中文](#简体中文) · [日本語](#日本語)

## 简体中文

这是一个单页网页工具，用于登记《火焰纹章：万缕千丝》五条路线的角色、培养路线与技能等级，并提示转职所需技能的差距。

### 功能

- 支持凯伊、迪托利希、赛奥朵拉、蕾达与救世篇。
- 登记角色、培养路线及 12 项技能等级。
- 高亮未满足的转职技能；“任选其一”按任意一项达标判断。
- 支持简体中文／日语角色与职业名称。
- 可新增自定义培养路线，并导入／导出本机数据。

### 使用与说明

发布后直接打开网页即可使用。所有登记数据只会保存在访问者自己的浏览器中。

资料参考：[角色一览](https://fire-emblem-fw.site/characters.html)、[职业一览](https://fire-emblem-fw.site/classes.html)、[GameWith 角色表](https://gamewith.jp/fefw/573109)、[GameWith 兵种表](https://gamewith.jp/fefw/573025)。

## 日本語

『ファイアーエムブレム 万紫千紅』のキャラ、育成ルート、技能レベルを記録し、クラスチェンジに必要な技能との差を確認できる単一 HTML ツールです。

### 機能

- カイ、ディートリヒ、セオドラ、レダ、救世主編の 5 ルートに対応。
- キャラ、育成ルート、12 種類の技能レベルを記録。
- 未達の転職技能を強調表示。「いずれか1つ」はいずれかの条件達成で判定。
- キャラ名・兵種名の簡体中文／日本語表示に対応。
- 自作育成ルートの追加と、ローカルデータのインポート／エクスポートに対応。

### 使い方・注意事項

公開後はウェブページを開くだけで利用できます。入力データは利用者自身のブラウザにのみ保存されます。
