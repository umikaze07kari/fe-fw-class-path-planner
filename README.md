# 万缕千丝 · 职业路线升级助手

单文件网页工具，用于登记《火焰之纹章 万缕千丝》四条主线的角色、培养路线与技能等级，并提示转职所需技能的差距。

## 使用

发布后的网页会自动打开工具。所有登记数据仅保存在访问者自己的浏览器中；可通过页面上的导入、导出按钮备份数据。
